# Rust-native library assessment

TSS can read compressed MP4 samples, decode MP3 and ALAC, encode a small H.264 elementary stream, match literal cue patterns and compile its existing optical shaders using the Rust libraries tested here. The tests also found three consequential differences. AAC edit-list handling shifts the imported cue clock. The MP4 reader omits release-critical colour metadata. The Intel Mac hardware encoder failed at session creation. The results qualify individual operations on the recorded fixtures. The production FFmpeg/FFprobe, Little CMS, native GPU and platform integrations remain the baselines.

## Application and library inventory

At the assessed release snapshot, the two Cargo manifests declare 31 dependencies counting build, dev and target-specific declarations. With the app lock at `6ca9c32083b8`, Rust 1.88 and `tauri/custom-protocol`, the two target graphs contain 378 distinct package/version pairs, including the app. Intel macOS selects 313 and Windows x64 MSVC selects 349. The graphs include compilers' procedural macros and build dependencies. A Cargo package can supply bindings to a native system library or compile bundled C code. Package counts cannot measure how much release binary code came from each language. ## Functionality-equivalence results

Each verdict applies to the feature, version, configuration, host and fixture named in its row. A successful operation at 160 × 90 cannot qualify a complete 3840 × 2160 export. Broader library substitution would also require tests for the unmeasured rows. No production dependency substitution is proposed by this assessment.

Other documented FFmpeg rewrites and bindings occupy different boundaries. The [Remade upstream compatibility matrix](https://github.com/Remade-With-Rust/remade_ffmpeg_rs/blob/482d511adfc5b323370367eb7f9e04b986c096ec/docs/compatibility.md) describes a Rust software pipeline. [OxideAV](https://github.com/OxideAV/oxideav-workspace) supplies composable codec and container crates. [rust-ffmpeg](https://github.com/zmwangx/rust-ffmpeg) exposes the installed native FFmpeg libraries through Rust bindings. Verifying an elementary codec, demuxer or wrapper is separate from verifying a substitute for the application's full CLI contract.
