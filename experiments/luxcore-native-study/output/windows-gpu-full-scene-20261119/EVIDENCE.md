# LuxCore native NVIDIA GPU full juice scene

This is an upstream LuxCore 2.11.2 stock 3-D juice/glass scene, not a TSS oil projection or fluid simulation. `juice-scene.png` is an actual 480×270 8-bit RGB render. **It is entirely white:** FFmpeg decoded raw RGB bytes and zero remained after removing byte 0xff. It is not a usable visual result.

The native Windows `luxcoreconsole.exe` used `scenes/juice/test.cfg` with `scene.file=scene.scn`, `PATHOCL`, `opencl.devices.select=0100000`, `film.hw.enable=0`, `opencl.native.threads.count=2`, `film.width=480`, `film.height=270`, `batch.haltspp=32`, `film.outputs.0.type=RGB_IMAGEPIPELINE`, and a fresh explicit `film.outputs.0.filename`. The clean test image pipeline was kept; the original full-scene `render.cfg` aberration, vignette and OIDN pipeline were not enabled. The full captured `render.log` confirms parsing four scene objects and allocating exactly one NVIDIA GTX 1650 Ti `(Type = OPENCL_GPU)` intersection device plus two Native CPU threads. The log records `Done` at 4.281 s and no error/exception/timeout lines were found by a case-insensitive word search. Completion and clean process exit do not establish correct scene rendering, correct light transport, fluid behavior or visual fidelity.

An untested lead for the all-white output is exposure: the upstream full-scene `render.cfg` uses `TONEMAP_LUXLINEAR` at exposure 0.0028571428265, f/4, sensitivity 100, whereas the selected `test.cfg` uses unparameterized `TONEMAP_LINEAR`. The captured image alone does not establish the cause. The physically based upstream exposure controls do not require enabling its vignette, chromatic aberration or denoiser.

A Rust supervisor held a cooperative reservation for the command and performed the UUID / sampled-idle preflight. The child finished with exit 0 and the reservation was released. There were five recorded NVIDIA samples (1068–2234 ms apart), maximum sampled utilization 100%, reported memory 313 MiB, temperature 58°C, power 26.45 W. Samples may miss peaks; the runner does not control unrelated graphics workloads or guarantee driver recovery. No macOS GPU job was run.
